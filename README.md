# Calculadora Python 2026
Repositório dedicado ao desenvolvimento de uma aplicação de calculadora em ambiente Python, estruturada para a 
consolidação de competências em programação, lógica computacional e conceção de interfaces gráficas de utilizador.

O presente projeto visa a implementação de uma calculadora funcional utilizando a biblioteca de componentes gráficos tkinter. 
A iniciativa integra a aplicação prática de paradigmas de desenvolvimento de software, contemplando a estruturação de layouts personalizados e a gestão de eventos associados a operações matemáticas.

## Funcionalidades
* Interface gráfica personalizada com paleta de cores própria.
* Operações matemáticas básicas estruturadas em ambiente modular.

## Tecnologias Utilizadas
* **Python**
* **Tkinter** (Interface Gráfica)

## Como Executar
1. Veja se você tem o Python instalado.
2. Clone o repositório ou descarregue os ficheiros fonte para o seu diretório de trabalho.
3. Execute o script principal através do terminal ou do seu ambiente de desenvolvimento integrado (IDE):
   ```bash
   python main.py
